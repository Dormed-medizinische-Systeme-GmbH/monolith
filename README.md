# Laravel Architecture Starter Documentation

Dieses Paket enthält die initiale, agententaugliche Projektdokumentation für die neue Laravel-Anwendung.

## Enthalten

- `AGENTS.md` — verbindliche Agent-Regeln
- `docs/` — Architektur, Security, Domain, Module, Infrastruktur und Implementierungsreihenfolge
- klare Zielstruktur für Multi-Subdomain-Laravel
- Docker/PostgreSQL-Grundlage
- Seeder-/Testing-Regeln
- Legacy-Mapping
- erste fachliche Leitplanken

## Verwendung

Die Dateien in das bestehende Laravel-Projekt übernehmen.

Danach sollte der Coding Agent zunächst:

1. `AGENTS.md` lesen,
2. `docs/README.md` lesen,
3. bestehendes Projekt prüfen,
4. vorhandene AI Rules prüfen,
5. aktuelle Laravel-Version und Skills/Boost prüfen,
6. erst danach Docker und Multi-Subdomain implementieren.

Diese Dokumentation ist bewusst kein vollständiges Fachschema. Die fachliche Discovery wird nach dem technischen Fundament anhand eines ersten CRM-Slices fortgesetzt.

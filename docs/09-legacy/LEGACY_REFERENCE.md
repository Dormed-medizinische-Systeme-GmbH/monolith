# Legacy Reference

## Zweck

Diese Datei dokumentiert nur die Rolle der bereitgestellten Altdefinitionen.

Vorhandene Dateien:

- Adressen XML
- Verkaufschancen XML
- Termine XML
- Tickets XML
- Serviceverträge_NEU XML

Sie stammen aus dem aktuellen System und werden als fachliche Referenz verwendet.
